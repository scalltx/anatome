# Estética Anatome

Site de Ana Tomé, massoterapeuta.

Os arquivos do site estão na raiz. Sirva esta pasta por HTTP para visualizar o site (o JavaScript usa módulos).

- `index.html`: estrutura e textos
- `styles.css` e `ana-tome.css`: estilos
- `script.js`: interações
- `config/site.js`: contatos e atendimentos
- `assets/`: imagens

As imagens de atendimentos são ilustrativas, geradas por IA.
